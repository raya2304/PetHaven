# Pet Haven – Pet Adoption Board

Pet Haven is a modern and responsive pet adoption website designed to help users discover pets looking for a loving home. The website provides an easy way to explore pet profiles, filter pets by category, search for specific pets, and send an adoption request.

## Features

* Responsive one-page website
* Attractive hero section
* Pet profile cards
* Search pets by name, breed, or location
* Filter pets by Dogs, Cats, and Rabbits
* Interactive pet details popup
* Pet age, breed, and location information
* Adoption process section
* Adoption request form
* Smooth hover effects and transitions
* Mobile-friendly design

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Unsplash Images

## How It Works

Users can browse available pets from the main pet listing section. The search bar allows users to find pets by name, breed, or location, while category buttons help narrow the results.

Clicking the **Meet Pet** button opens a detailed profile containing the pet's information and personality description. Users can then move to the adoption request section to submit their details.

## JavaScript Functionality

JavaScript is used to:

* Store pet information in an array
* Dynamically generate pet cards
* Search pets
* Filter pets by category
* Display individual pet details
* Open and close the pet modal
* Handle the adoption form
* Display a submission message

## Design

The website uses a warm, friendly color palette with rounded cards, large pet photography, smooth transitions, and responsive layouts to create a welcoming adoption experience.
